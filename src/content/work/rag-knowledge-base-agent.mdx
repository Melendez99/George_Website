A portfolio build for businesses that want to ask questions of their own documents. A chat agent searches a Supabase vector store and answers from what it finds, and three small pipelines keep that store in step with a Google Drive folder.

## What the system does

- Answers chat questions with an AI agent that looks up the right passages first
- Adds a new Drive file to the vector store when it is uploaded
- Replaces the old entries when a file is updated, so answers do not use stale text
- Removes the entries when a file is deleted
